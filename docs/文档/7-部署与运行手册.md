## 2. 中间件部署

### 2.1 MySQL（3 个实例）

创建 3 个数据库实例（可用 Docker 快速启动）：

```bash
# db_0 - 端口 3306
docker run -d --name mysql-0 -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=88888888 \
  mysql:8.0

# db_1 - 端口 3307
docker run -d --name mysql-1 -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=88888888 \
  mysql:8.0

# db_2 - 端口 3308
docker run -d --name mysql-2 -p 3308:3306 \
  -e MYSQL_ROOT_PASSWORD=88888888 \
  mysql:8.0
```

在每个实例创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS db_0;
-- db_1 实例执行: CREATE DATABASE IF NOT EXISTS db_1;
-- db_2 实例执行: CREATE DATABASE IF NOT EXISTS db_2;
```

> **注意**：ShardingSphere 配置中 `ds_0` 实际指向 `db_0` 数据库，密码默认 `88888888`。如需修改，编辑各服务的 `sharding.yaml`。

### 2.2 Redis

```bash
docker run -d --name redis -p 6379:6379 \
  redis:8.0 redis-server --requirepass 123456
```

或在 `ticket-service/src/main/resources/application.yml` 中通过环境变量配置：

```yaml
spring.data.redis:
  host: ${REDIS_HOST:127.0.0.1}
  port: 6379
  password: ${REDIS_PASSWORD:123456}
```

### 2.3 RocketMQ

需要启动 NameServer 和 Broker：

```bash
# NameServer
docker run -d --name rmqnamesrv -p 9876:9876 \
  apache/rocketmq:5.3.0 sh mqnamesrv

# Broker
docker run -d --name rmqbroker -p 10911:10911 -p 10909:10909 \
  --link rmqnamesrv:namesrv \
  -e "NAMESRV_ADDR=namesrv:9876" \
  apache/rocketmq:5.3.0 sh mqbroker
```

> 本项目默认使用 `172.22.32.238:9876`，可在各服务 `application.yml` 修改。

## 3. 项目构建

```bash
# 克隆代码
git clone <仓库地址>
cd 12306Pro

# 编译打包（跳过测试）
mvn clean package -DskipTests
```

构建成功后各服务的 jar 包位于 `target/` 目录。

## 4. 数据库初始化

### 4.1 DDL

在 `ds_0`（localhost:3306）的 `db_0` 中执行 DDL：

```bash
mysql -u root -p88888888 -h localhost -P 3306 db_0 < docs/sql/schedule_ddl.sql
mysql -u root -p88888888 -h localhost -P 3306 db_0 < docs/sql/seat_bitmap_ddl.sql
mysql -u root -p88888888 -h localhost -P 3306 db_0 < docs/sql/order_ddl.sql
mysql -u root -p88888888 -h localhost -P 3306 db_0 < user-service/src/main/resources/db/passenger_ddl.sql
```

### 4.2 种子数据

ticket-service 首次启动时会自动加载 `schema.sql` 和 `data.sql`（包含 981 趟车次 + 169 个站点）。

> **首次启动**：将 `ticket-service/src/main/resources/application-dev.yml` 中的 `spring.sql.init.mode` 改为 `always`。
> **首次启动后**：改回 `never`，避免重复执行。

## 5. 服务启动顺序

按依赖顺序启动（建议每个服务开一个终端）：

```bash
# 1. 编译公共模块（如未做过）
mvn install -pl common -DskipTests

# 2. 启动用户服务
mvn -pl user-service spring-boot:run
# 或: java -jar user-service/target/user-service-0.0.1-SNAPSHOT.jar

# 3. 启动票务服务（会自动预热数据，首次约 1~2 分钟）
mvn -pl ticket-service spring-boot:run

# 4. 启动订单服务
mvn -pl order-service spring-boot:run

# 5. 启动网关
mvn -pl gateway spring-boot:run
```


## 7. 常见问题排查

### 7.1 端口冲突

```bash
# 查看占用进程
netstat -ano | grep :8092
# Windows 杀进程
taskkill //F //PID <PID>
```

端口分配：

| 服务 | 端口 | 冲突说明 |
|------|------|----------|
| gateway | 8080 | 常见冲突源 |
| user-service | 8081 | - |
| order-service | 8083 | - |
| ticket-service | 8092 | 避开 RocketMQ 默认 8082 |
| RocketMQ Broker | 8082 | 不要改 |

### 7.2 Redis 连接失败

```bash
redis-cli -h <host> -p 6379 -a 123456 ping
# 期望返回: PONG
```

### 7.3 ShardingSphere 分片不生效

确认 `ds_0/ds_1/ds_2` 三个实例都可达，密码与 `sharding.yaml` 一致。

### 7.4 数据重复

如果 `train_template_stopover` 出现重复行，执行：

```sql
-- 删除重复（保留最小 ID）
DELETE t1 FROM train_template_stopover t1
INNER JOIN train_template_stopover t2
ON t1.train_code=t2.train_code AND t1.station_name=t2.station_name
   AND t1.station_index=t2.station_index AND t1.id > t2.id;

-- 加唯一约束
ALTER TABLE train_template_stopover
ADD UNIQUE KEY uk_train_station_idx (train_code, station_name, station_index);
```

### 7.5 排期窗口过期

如果查票返回空，可能是窗口过期。重启 ticket-service 会自动追补，或手动修复：

```sql
UPDATE schedule_window SET window_start='2026-06-13', window_end='2026-06-27' WHERE id=1;
```

重启 ticket-service 后会自动补齐数据。
